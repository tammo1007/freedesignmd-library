# freedesignmd — free design library for the AI era

Copy-paste React components, complete landing pages and DESIGN.md design systems for AI coding agents.
Everything here is MIT-licensed and installs byte-identical to the live preview on **[freedesignmd.com](https://freedesignmd.com)**.

| Folder | What it is |
| --- | --- |
| `library/` | 68 components — Liquid Glass, liquid metal, dither, buttons, forms, heroes, tables, effects, text, interactions. One file each, `react` is the only import. |
| `design-systems/` | 30 DESIGN.md systems (tokens, type, motion, components) your agent can follow. |
| `landingpages/` | 13 complete single-file landing pages, each with its own `DESIGN.md`. |
| `public/img/` | Demo photography used by the examples. Copy next to your page or swap in your own. |

## Use it
- Browse and copy on [freedesignmd.com](https://freedesignmd.com), or install with the shadcn CLI:
  `npx shadcn@latest add https://freedesignmd.com/r/glass-button.json`
- Paste a `DESIGN.md` into Claude Code, Cursor, Lovable or v0 as context.
